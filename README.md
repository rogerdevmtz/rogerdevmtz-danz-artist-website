# DANZ · DJ en A Coruña

Landing del proyecto «Muestra el talento de tu amigo artista con un website» de 4Geeks. Desarrollada sobre la plantilla oficial `4GeeksAcademy/html-hello`.

## Archivos

- `index.html`: portada, sobre mí, trayectoria, próximas presentaciones y contacto; HTML semántico, accesibilidad y Schema.org mediante Microdata `Person`.
- `styles.css`: diseño adaptable, tipografía y estados de foco.
- `assets/danz/`: cinco fotografías WebP utilizadas en la web y favicon SVG.

## Abrir

Abre `index.html` en el navegador. Las fuentes de Google Fonts requieren conexión a internet.

La web utiliza únicamente HTML y CSS, sin JavaScript ni frameworks. Los espacios de vídeo esperan material del artista; las próximas actuaciones están por anunciar.
